# TURMO Display Control — Windows Application

A professional Windows application for controlling TURMO 3.5" USB displays (VID:PID 1A86:5722).

## Features

- **Modern GUI** (v0.2): Dashboard, live screen preview, light or dark window, and a small Minimalist window
- **Loading screen** while the app starts (the logo fills as start-up progresses)
- **Theme Gallery** with all built-in themes (Cyberpunk Neon, Matrix Terminal, Minimal Dark, etc.)
- **Visual Drag-and-Drop Theme Editor** — create custom layouts visually
- **Portrait & Landscape** orientation selector
- **Real-time Sensor Monitoring**: CPU/GPU/RAM/Network/Disk
- **CPU Temperature** via LibreHardwareMonitor + PawnIO driver
- **NVIDIA GPU Monitoring** via NVML (multi-GPU support)
- **Graph Customization** — select sensors, ranges, colors, history length
- **Brightness & Refresh Rate** controls
- **System Tray Integration** — a click opens a quick panel (status, CPU/GPU/RAM, Start/Stop, brightness), a double click opens the window
- **Windows Startup** — optional auto-start on login
- **Automatic USB Detection & Reconnection**
- **Local Settings Persistence** (JSON config)
- **Portable Mode** — run from USB without installation
- **One-Click Windows Installer**
- **No Cloud Dependency** — fully local operation

## Quick Start

### Portable Mode (No Installation)
1. Extract all files to a folder
2. Run `launch_portable.bat` — settings stored next to the executable
3. Or run `TURMO-Display-Control.exe` directly

### Windows Installation (setup)
1. Run `TURMO-Setup-<version>.exe` and accept the administrator prompt
2. Choose the options: desktop shortcut, start with Windows (both off by default)
3. Launch from Start Menu → **TURMO Display Control**

The setup also registers the elevated task that reads the CPU temperature, so the app never asks for it again.
The setup is not code-signed: Windows SmartScreen may warn. Installing over an older version keeps your settings and
custom themes. Uninstalling asks whether to delete them (the default is to keep them).

## Requirements

- Windows 10/11 (64-bit)
- TURMO 3.5" USB display connected (CH340 serial, VID:PID 1A86:5722)
- **PawnIO driver v2.2.0+** (for CPU temperature) — install from official source
- **LibreHardwareMonitor.NET10** (for CPU temperature sensors)
- NVIDIA GPU (optional, for GPU monitoring)

## Hardware Setup

1. Install PawnIO driver (required for CPU temperature):
   - Download from official source
   - Run installer with `-install -silent` arguments
   - Approve UAC prompt

2. Install LibreHardwareMonitor:
   - Download `LibreHardwareMonitor.NET10` from official releases
   - Install to `C:\Program Files\LibreHardwareMonitor.NET10`

3. Connect TURMO display via USB
   - Should appear as COM port (CH340)
   - Auto-detected by the application

## Usage

### Main Pages

**Dashboard** — device status, Start / Stop / Restart / Test image, live view of the display, quick theme
**Monitor** — start/stop the display monitor, view logs
**Live Preview** — real-time preview of the display output with sensor values
**Gallery** — all themes, Landscape or Portrait previews
**Theme Editor** — visual drag-and-drop theme editor
**Sensors & Graphs** — choose graph sensors, ranges, colors
**Settings** — sensors, units, widgets, startup, brightness, App theme (Default, Minimalist); the Theme switch in the sidebar toggles dark and light
**Diagnostics** and **About** — checks, version info

### Theme Editor

1. Select **Theme Editor** tab
2. Choose widgets from the palette on the left
3. Drag widgets on the canvas to position them
4. Click a widget to edit its properties (sensor, color, size, etc.)
5. Use **Save Theme** to write changes to the theme file
6. **Export/Import JSON** for sharing themes

### System Tray

- Click the tray icon → quick panel above the taskbar (setting `quick_panel`, on by default; off: opens the window)
- Double click → show the window
- Right-click → Open TURMO, Start/Stop Monitor, Quit
- Monitor continues running when the window is hidden

### Windows Startup

- Enable in **Settings** tab → "Start TURMO monitor on Windows login"
- Runs monitor automatically at login (headless, no GUI)

## Configuration

- Settings: `%APPDATA%\TURMO\settings.json` (portable mode, started with `launch_portable.bat`: next to the exe)
- Logs: `%LOCALAPPDATA%\TURMO\logs` (old logs are removed by themselves: Settings > Logs sets how many days and how many MB to keep)
- Custom themes: `%APPDATA%\TURMO\themes\custom`
- USB: if the display is unplugged, off or asleep, the Monitor keeps trying by itself (0.5, 1, 2, then 5 s) and the app shows
  Connecting, Reconnecting or Not found; it never needs a restart
- Themes: `themes\<name>\theme.json` (landscape) and `<name>-320x480` (portrait), generated by `scripts\generate_themes.py`

## Building from Source

Run the app from the project virtual environment:
```
.venv-win\Scripts\python.exe scripts\turmo_app_enhanced.py
```

Build the two executables (GUI and Monitor) with PyInstaller:
```
.venv-win\Scripts\python.exe scripts\build_release.py vX.Y.Z
```

Current version: see `scripts\app_version.py`.
