TURMO Display Control

Guide for version 0.3.0 · Windows 10/11 (64-bit) · TURMO 3.5" USB display

1. Install

  1. Run TURMO-Setup-v0.3.7.3.exe and accept the administrator prompt (it is needed once, to register the task that reads the CPU temperature).
  2. Choose the options: Desktop shortcut and Start TURMO with Windows. Both are off by default.
  3. Open TURMO Display Control from the Start Menu.
The setup is not code-signed yet, so Windows SmartScreen may warn. Installing over an older version keeps your settings and your own themes.

Portable use: extract the files to a folder and run launch_portable.bat; the settings are then stored next to the program.

2. First start

A welcome dialog checks four things and must be closed with Done: the display, the CPU temperature helper (Enable asks for one administrator confirmation), the language (English, Français or Português) and the look of the window (Default or Minimalist).

3. Everyday use

PageWhat it does
DashboardDevice status, Start / Stop / Restart / Test image, orientation (Landscape or Portrait; the display follows at once), theme and brightness.
MonitorStarts and stops the Monitor, the program that sends the pictures to the display; shows its logs.
Live PreviewThe display's output on screen, with the real sensor values.
GalleryAll themes. Your own themes get a picture, a bin (delete), a pencil (edit) and a copy button; the organize icon (top right) is on every card.
Theme EditorDrag widgets onto the canvas and set their sensor, colour and size. The list In this theme shows the layers; the arrows on the chosen row move it up or down. Save theme writes it; Export / Import JSON shares it.
Sensors & GraphsGraph sensors, ranges, colours, history length.
SettingsUnits, widgets, start with Windows, brightness, App theme (Default or Minimalist), Logs (a switch to stop writing logs, days and MB to keep, Clean now, Open folder).
Diagnostics, AboutChecks (including the USB link and serial latency) and version information.

System tray

One click on the icon opens a quick panel (status, CPU / GPU / RAM, Start / Stop, brightness); a double click opens the window; right-click offers Open, Start/Stop Monitor and Quit. The Monitor keeps running when the window is hidden.

4. If the display is unplugged or asleep

The Monitor never needs a restart. It looks for the display again by itself (after 0.5, 1, 2, then every 5 seconds) and the app shows Connecting, Reconnecting or Not found until it is back. You can press Start with no display plugged in.

5. Where things are

Settings%APPDATA%\TURMO\settings.json
Your themes%APPDATA%\TURMO\themes\custom
Logs%LOCALAPPDATA%\TURMO\logs (old logs are removed by themselves)

6. Uninstall

Use Windows Settings > Apps. The uninstaller removes the CPU temperature task and asks whether to delete your settings and themes; the default is to keep them.

7. Good to know

  • The program works fully offline; nothing is sent to the cloud.
  • The menus are in English; French and Portuguese wording is still a draft.
